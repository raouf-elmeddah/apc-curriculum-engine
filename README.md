# 🇩🇿 محرك المناهج التكوينية بالمقاربة بالكفاءات (APC Curriculum Engine)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python: 3.10+](https://img.shields.io/badge/Python-3.10%2B-emerald.svg)](https://python.org)
[![INFEP Standard](https://img.shields.io/badge/Standard-INFEP%20%2F%20CFPA%20(Algeria)-red.svg)](#)
[![Pedagogy: APC](https://img.shields.io/badge/Pedagogy-Approche%20Par%20Comp%C3%A9tences-amber.svg)](#)

نظام متكامل ومفتوح المصدر لتحليل البرامج التكوينية الرسمية لوزارة التكوين والتعليم المهنيين بالجزائر (**INFEP / CFPA / INSFP**)، وتوليد شجرة المنهاج البيداغوجي الشامل لكل السداسيات وفق **المقاربة بالكفاءات (APC)** على مدار **17 أسبوعاً** لكل سداسي، مع تجميع منهاج تفاعلي ويب عالي الجودة يدعم الطباعة البيداغوجية المعزولة لجميع الوثائق.

---

## 🌟 الميزات الجوهرية (Key Features)

1. **التقيد الصارم بالجدول الزمني الرسمي للـ INFEP:**
   - السداسيات (S1, S2, S3): **17 أسبوعاً** × 29 ساعة/أسبوع = **493 ساعة** لكل سداسي.
   - السداسي الرابع (S4): **5 أسابيع** مقاييس نظرية وتطبيقية (145 س) + **348 ساعة** تربص تطبيقي ميداني في مؤسسة = **493 ساعة**.
   - الحجم الإجمالي للدبلوم: **1972 ساعة**.

2. **3 وثائق بيداغوجية مستقلة لكل درس (3 Dedicated Resources per Lesson):**
   - 👨‍🏫 **البطاقة التقنية البيداغوجية (للأستاذ):** الكفاءات المستهدفة، شروط الإنجاز، معايير الأداء، والتوجيهات البيداغوجية.
   - 📋 **مخطط الدرس الرسمي بالمقاربة بالكفاءات (Plan de Leçon APC):** شبكة سير الحصة المعتمدة في التكوين المهني الجزائري المكونة من **5 مراحل** (وضعية الانطلاق، بناء التعلمات، التطبيق، التقويم النهائي، الإدماج والاستثمار) مع شبكة الملاحظات وخانة توقيع الأستاذ والمفتش.
   - 👨‍🎓 **محتوى الدرس المفصل للمتربص:** شرح نظري غير مختصر، أمثلة توضيحية، خوارزميات وأكواد برمجية كاملة، وورشة تطبيقية مخبرية خطوة بخطوة (Fiche TP).

3. **منهاج تفاعلي متكامل (Interactive Syllabus SPA):**
   - واجهة مستخدم سريعة باللغة العربية مع بحث فوري في الدروس وتصفح السداسيات والمقاييس.
   - تبويبات مستقلة لكل وثيقة بيداغوجية.

4. **محرك الطباعة المعزول متعدد الصفحات (Isolated Print Engine):**
   - طباعة نظيفة بدون اقتطاع الصفحات (يتجاوز مشكلة المتصفحات في قص الصفحات الفردية).
   - هوامش A4 قياسية دقيقة (20mm أعلى/أسفل، 15mm يمين/يسار).
   - اتجاه الكتابة والجداول من اليمين إلى اليسار (RTL) مع توسيط رؤوس الجداول تلقائياً.

## 🚀 كيفية استخدام السكريبت (How to Use the Script)

يتضمن المستودع سكريبت القيادة الموحد `apc_cli.py` الذي يتيح إدارة المنهاج وتجميعه بأوامر بسيطة:

### 1. المتطلبات الأساسية (Prerequisites)
تأكد من تثبيت Python 3.10 أو أحدث. (المشروع يعتمد بالأساس على المكتبة المعيارية القياسية لـ Python دون الحاجة لمكتبات خارجية معقدة):
```bash
python --version
```

*(اختياري)* لتثبيت المتطلبات الإضافية:
```bash
pip install -r requirements.txt
```

---

### 2. الأوامر الأساسية (CLI Commands)

#### أ. عرض إحصائيات المنهاج والدروس (`status`):
يعرض تقريراً فورياً لجميع السداسيات، عدد المقاييس، الدروس المفعلة، وحالة تجميع المنهاج التفاعلي:
```bash
python apc_cli.py status
```
*المخرجات النموذجية:*
```text

📁 SEMESTRE_1      | المقاييس: 8  | الدروس: 136 (17 أسبوعاً)
📁 SEMESTRE_2      | المقاييس: 9  | الدروس: 153 (17 أسبوعاً)
📁 SEMESTRE_3      | المقاييس: 8  | الدروس: 136 (17 أسبوعاً)
📁 SEMESTRE_4      | المقاييس: 4  | الدروس: 20  (17 أسبوعاً)
📁 STAGE_PRATIQUE  | وثائق التربص الميداني والمرافقة: 4
----------------------------------------------------------------------
إجمالي المقاييس : 29

======================================================================
```

---

#### ب. تجميع وإعادة بناء المنهاج التفاعلي (`build`):
يقوم بفحص جميع ملفات الماركدوان لكل السداسيات والمقاييس، وتوليد ملف HTML تفاعلي متكامل جاهز للتشغيل والطباعة في أي متصفح:
```bash
python apc_cli.py build
```
أو تشغيل السكريبت المباشر:
```bash
python build_html_syllabus.py
```
الملف الناتج يكون متاحاً في:
`INT1204 - Programmation BT/منهاج_البرمجة_التفاعلي_Syllabus.html`
*(يمكنك النقر عليه مرتين لفتحه فوراً في متصفحك أو توزيعه على الأساتذة والمتربصين)*.

---

#### ج. إثراء الدروس بالمحتوى التطبيقي والنظري (`enrich`):
يقوم بتحديث نصوص كافة الدروس وورشات العمل المخبرية بمحتوى تفصيلي غني بالأمثلة والأكواد البرمجية:
```bash
python apc_cli.py enrich
```

## 🤖 استخدام المهارة لتوليد أي تخصص جديد من ملف PDF (Agent Skill Usage)

هذا المستودع يحتوي على ملف المهارة البيداغوجية [`SKILL.md`](SKILL.md) والمتوافق مع أدوات الذكاء الاصطناعي (مثل **Antigravity**, **Gemini CLI**, **Claude Code**, **Cursor**).

### خطوات توليد منهاج تخصص جديد:
1. أنشئ مجلداً جديداً لتخصصك وضع فيه ملف الـ PDF الرسمي للبرنامج:
   ```text
   ELECTRO_BT/
     └── programme_officiel_infep.pdf
   ```
2. انسخ ملف [`SKILL.md`](SKILL.md) إلى مجلد المهارات لديك (`~/.gemini/config/skills/apc-curriculum-generator/SKILL.md`).
3. افتح موجه الأوامر أو المحادثة مع الوكيل واكتب:
   > *"استخدم مهارة `apc-curriculum-generator` لتحليل ملف PDF وبناء شجرة المنهاج الشامل المقسم على 17 أسبوعاً وتوليد المنهاج التفاعلي."*
4. سيقوم الذكاء الاصطناعي بتنفيذ خطة العمل تلقائياً:
   - استخراج مصفوفة الكفاءات وتوقيت المقاييس (نظري + تطبيقي).
   - تقسيم المنهج على 17 أسبوعاً بدقة.
   - صياغة البطاقات التقنية ومخططات الدروس ودروس المتربصين.
   - استدعاء `build_html_syllabus.py` لإنتاج الحقيبة التفاعلية.

## 🖨️ دليل الطباعة الرسمية (Printing Guide)

عند فتح ملف المنهاج التفاعلي `منهاج_البرمجة_التفاعلي_Syllabus.html`:
1. اختر السداسي والمقياس والدرس المطلوب من القائمة الجانبية.
2. ستجد في أعلى الصفحة ثلاثة أزرار طباعة ملونة:
   - 🔵 **طباعة البطاقة التقنية:** تطبع بطاقة تحضير الأستاذ الرسمية مع الكفاءات وشروط الإنجاز.
   - 🟠 **طباعة مخطط الدرس (APC):** تطبع مخطط سير الحصة الخماسي المعتمد في استمارة التكوين المهني مع خانات التوقيع.
   - 🟢 **طباعة درس المتربص:** تطبع المحتوى الدراسي الكامل والتطبيقات المخبرية لتوزيعها على المتربصين.
3. تفتح نافذة الطباعة تلقائياً بهوامش متناسقة مقاس A4 وبدون أي تشويه أو اقتطاع.
