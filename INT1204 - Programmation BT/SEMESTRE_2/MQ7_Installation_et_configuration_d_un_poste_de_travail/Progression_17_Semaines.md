# التدرج البيداغوجي لـ 17 أسبوعاً - المقياس: MQ7
**تثبيت وتهيئة منصب العمل**  
*الحجم الساعي: 4 ساعات أسبوعياً ورشات عملية (100% TP) - 68 ساعة*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى والأهداف المستهدفة |
| :---: | :--- | :---: | :--- |
| **W01** | مكونات منصب العمل ومتطلبات البيئة والتشغيل | 4H TP | فحص المتطلبات المادية لمكان العمل: التغذية الكهربائية، التأريض، والمنافذ |
| **W02** | التثبيت الفيزيائي للوحة الأم والمعالج ومروحة التبريد | 4H TP | تركيب اللوحة الأم في الصندوق المعدني، تثبيت المعالج في المقبس، وربط المروحة |
| **W03** | تثبيت الذاكرة الحية (RAM) وبطاقات التوسعة (PCIe) | 4H TP | تثبيت شرائح الذاكرة في القنوات الصحيحة (Dual Channel) وتركيب بطاقة الشاشة |
| **W04** | تثبيت وسائط التخزين ومحركات الأقراص (SATA / M.2 NVMe) | 4H TP | تركيب القرص الصلب SSD/HDD، ربط كابلات البيانات وكابلات التغذية الكهربائية |
| **W05** | توصيل لوحة التحكم الأمامية للعلبة (Front Panel Connectors) | 4H TP | ربط أسلاك زر التشغيل، إعادة التشغيل، لمبات LED، ومنافذ USB والصوت الأمامية |
| **W06** | التوصيل الخارجي للمحيطيات (الشاشة، لوحة المفاتيح، الفأرة، الطابعة) | 4H TP | ربط كابلات الفيديو (HDMI, DisplayPort) ومحيطيات USB واختبار أول إقلاع |
| **W07** | إعداد برنامج الإقلاع وإعدادات البيوس المتقدمة (UEFI / BIOS) | 4H TP | ضبط الساعة، تفعيل الوضع الافتراضي، إعدادات AHCI، وتفعيل Secure Boot |
| **W08** | إعداد وسائط التثبيت الإقلاعية (Création de supports Bootables) | 4H TP | استخدام أداة Rufus لحرق نظام التشغيل Windows 10/11 على فلاش ديسك بنمط GPT |
| **W09** | تقسيم القرص الصلب وتثبيت نظام التشغيل Windows | 4H TP | تهيئة جدول التقسيم GPT، إنشاء الأقسام C و D، وتتبع مراحل التثبيت |
| **W10** | تثبيت وتحديث برامج التشغيل (Pilotes / Drivers) | 4H TP | التعرف على الأجهزة المجهولة في Device Manager وتثبيت برامج التشغيل الرسمية |
| **W11** | تثبيت وتفعيل الحزمة المكتبية (Microsoft Office / LibreOffice) | 4H TP | تثبيت برامج معالجة النصوص والجداول والعروض وتخصيص إعدادات المستخدم |
| **W12** | تثبيت بيئات التطوير والبرمجيات التخصصية للمبرمج | 4H TP | تثبيت Visual Studio Code، Code::Blocks، مترجم GCC، وخادم الويب المحلي |
| **W13** | تثبيت برمجيات الحماية ومكافحة الفيروسات وجدار الحماية | 4H TP | ضبط Windows Defender، تحديث قواعد البيانات الفيروسية، وفحص النظام |
| **W14** | إعداد الحسابات وصلاحيات المستخدمين وسياسات الأمان | 4H TP | إنشاء حسابات المستخدمين (User Accounts)، ضبط صلاحيات المسؤول (Admin) |
| **W15** | تهيئة إعدادات الشبكة المحلية ومشاركة الملفات والطابعات | 4H TP | ضبط عنوان IP الثابت والديناميكي، ومشاركة مجلد عبر الشبكة وضبط الأذونات |
| **W16** | ورشة متكاملة: تجميع وتثبيت منصب عمل كامل وتسليمه جاهزاً | 4H TP | تجميع منصب عمل كامل من الصفر، تثبيت برامجه، وتحرير بطاقة التسليم |
| **W17** | التقييم التحصيلي والامتحان التطبيقي في تثبيت منصب العمل | 4H TP | اختبار عملي فردي لقياس سرعة وجودة تجهيز منصب عمل معلوماتي |
