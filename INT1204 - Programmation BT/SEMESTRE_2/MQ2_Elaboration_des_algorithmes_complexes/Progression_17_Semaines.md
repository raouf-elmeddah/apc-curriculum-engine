# التدرج البيداغوجي لـ 17 أسبوعاً - المقياس: MQ2
**إعداد الخوارزميات المعقدة**  
*الحجم الساعي: 4 ساعات أسبوعياً (2H نظري + 2H مخبر) - 68 ساعة*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى والأهداف المستهدفة |
| :---: | :--- | :---: | :--- |
| **W01** | المجموعات في الخوارزميات: المفهوم والتصريح | 2H نظري + 2H مخبر | تعريف نوع المجموعة (Ensemble)، التصريح، والتمثيل بالبايت في الذاكرة |
| **W02** | العمليات الأساسية على المجموعات (الاتحاد والتقاطع) | 2H نظري + 2H مخبر | خوارزميات فحص الانتماء، الإضافة، الحذف، الاتحاد والتقاطع |
| **W03** | التسجيلات أو المقالات (Les Articles / Enregistrements) | 2H نظري + 2H مخبر | مفهوم السجل كبنية بيانات غير متجانسة والتصريح بأنواع مركبة جديدة |
| **W04** | التعامل مع حقول التسجيل وتمريرها | 2H نظري + 2H مخبر | الوصول إلى الحقول بالنقطة (Champ)، القراءة، الكتابة، واستخدام تعليمة Avec |
| **W05** | جداول التسجيلات (Tableaux d'enregistrements) | 2H نظري + 2H مخبر | إنشاء قاعدة بيانات مصغرة في الذاكرة لتخزين قائمة متربصين بسجلاتهم |
| **W06** | المؤشرات وعناوين الذاكرة (Les Pointeurs) | 2H نظري + 2H مخبر | مفهوم العنوان والمؤشر، التصريح بمؤشر، وعامل استخراج العنوان وعامل القيمة |
| **W07** | العمليات الحسابية والديناميكية على المؤشرات | 2H نظري + 2H مخبر | الحجز الديناميكي للذاكرة (Allouer)، تحرير الذاكرة (Libérer)، والمؤشر الفارغ NIL |
| **W08** | مفهوم الملفات في الخوارزميات (Les Fichiers) | 2H نظري + 2H مخبر | الفرق بين الذاكرة الحية والتخزين الدائم، التصريح بملف متجانس |
| **W09** | فتح وإنشاء الملفات والقراءة والكتابة السجلاتية | 2H نظري + 2H مخبر | تعليمات: Ouvrir, Fermer, Lire_Fichier, Ecrire_Fichier وفحص نهاية الملف EOF |
| **W10** | معالجة وتحيين الملفات (Recherche et Mise à jour) | 2H نظري + 2H مخبر | البحث التتابعي داخل ملف، تعديل سجل معين، وإضافة سجلات جديدة |
| **W11** | البرمجة الإجرائية: الإجراءات (Les Procédures) | 2H نظري + 2H مخبر | تفكيك الخوارزمية، رأس الإجراء، استدعاء الإجراء، والمتغيرات المحلية والعامة |
| **W12** | تمرير الوسائط في الإجراءات: بالقيمة وبالمرجع | 2H نظري + 2H مخبر | التمييز بين المعاملات الصورية والمعاملات الحقيقية والتمرير بالمتغير (Var) |
| **W13** | الدوال الخوارزمية (Les Fonctions) | 2H نظري + 2H مخبر | صياغة الدوال، تحديد النوع المرجع، تعليمة Retourner، والدوال الرياضية |
| **W14** | الخوارزميات التكرارية الارتجاعية (La Récursivité - المبدأ) | 2H نظري + 2H مخبر | مفهوم العودية، شرط التوقف الحرج، ومكدس النداءات (Pile d'exécution) |
| **W15** | تطبيقات متقدمة في العودية (المضروب، متتالية فيبوناتشي) | 2H نظري + 2H مخبر | خوارزمية حساب Factorielle العودية وأبراج هانوي (Tours de Hanoï) |
| **W16** | حوصلة عامة ومشروع تطبيقي تركيبي في الخوارزميات المتقدمة | 1H نظري + 3H مخبر | مشروع متكامل لإدارة سجلات ملفات المتربصين باستخدام الإجراءات والدوال |
| **W17** | التقييم التحصيلي والامتحان النهائي لمقياس الخوارزميات المعقدة | 2H كتابي + 2H تطبيقي | امتحان شامل يقيس الكفاءة المعيارية لمقياس MQ2 |
