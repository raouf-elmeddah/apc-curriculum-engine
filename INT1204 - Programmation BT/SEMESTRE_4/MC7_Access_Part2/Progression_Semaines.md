# التدرج البيداغوجي للمقياس: MC7 (الجزء 2)
**قواعد البيانات أكسس Access - النماذج والتقارير والماكرو**  
*الحجم الساعي: 8 ساعات أسبوعياً مكثفة (4H نظري + 4H مخبر) - 40 ساعة*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى والأهداف المستهدفة |
| :---: | :--- | :---: | :--- |
| **W01** | استعلامات الإجراء والتعديل في Access (Requêtes Action) | 4H نظري + 4H مخبر | استعلامات الإلحاق (Ajout)، الحذف (Suppression)، والتحديث (Mise à jour) |
| **W02** | تصميم النماذج التفاعلية في نمط التصميم (Formulaires en Mode Création) | 4H نظري + 4H مخبر | إضافة مربعات النصوص، أزرار الأوامر، الصور، وتنسيق الألوان والخطوط |
| **W03** | النماذج الفرعية والتبويبات (Sous-formulaires et Contrôle Onglet) | 4H نظري + 4H مخبر | عرض بيانات الفاتورة وسلعها في نفس الشاشة بنموذج فرعي متزامن 1..N |
| **W04** | تصميم وطباعة التقارير الرسمية المصنفة (États / Reports) | 4H نظري + 4H مخبر | تجميع البيانات وفرزها، حساب المجاميع الإجمالية وتجهيز الفواتير للطباعة |
| **W05** | أتمتة التطبيق عبر وحدات الماكرو ولوحة التبديل (Switchboard / Navigation) | 4H نظري + 4H مخبر | برمجة أزرار فتح وغلق النوافذ وتصميم الشاشة الرئيسية لواجهة المستخدم |
