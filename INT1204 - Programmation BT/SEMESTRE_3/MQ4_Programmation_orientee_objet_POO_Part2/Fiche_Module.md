# بطاقة تقديم المقياس: البرمجة كائنية التوجه POO C++ - الجزء الثاني (MQ4 (الجزء 2))

* **الرمز:** MQ4 (الجزء 2).
* **الحجم الساعي:** 3 ساعات أسبوعياً (1H نظري + 2H مخبر) - 51 ساعة.
* **مكان التكوين:** مخبر البرمجة.
* **الوسائل:** السبورة، جهاز العرض، حواسيب متصلة، بيئة تطوير C++.

## 1. الهدف المعياري للمقياس (Objectif Modulaire)
> **السلوك المتوقع (Comportement attendu):**  
> في نهاية هذا الجزء، يتحكم المتربص في المفاهيم المتقدمة للـ POO: الوراثة (Héritage)، تعدد الأشكال (Polymorphisme)، الأصناف المجردة، القوالب (Templates)، إدارة الاستثناءات (Exceptions)، والربط بقواعد البيانات عبر ODBC/MySQL.
