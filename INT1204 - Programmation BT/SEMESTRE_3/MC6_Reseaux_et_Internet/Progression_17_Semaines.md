# التدرج البيداغوجي لـ 17 أسبوعاً - المقياس: MC6
**الشبكات والإنترنت (Réseaux et Internet)**  
*الحجم الساعي: 4 ساعات أسبوعياً (2H نظري + 2H مخبر) - 68 ساعة*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى والأهداف المستهدفة |
| :---: | :--- | :---: | :--- |
| **W01** | مفاهيم أساسية في الشبكات وأهميتها في الأنظمة المعلوماتية | 2H نظري + 2H مخبر | أهداف الشبكة، مشاركة الموارد، والاتصال بين الأجهزة في بيئة المؤسسة |
| **W02** | تصنيف الشبكات حسب النطاق الجغرافي (PAN, LAN, MAN, WAN) | 2H نظري + 2H مخبر | خصائص الشبكة المحلية، الحضرية، والواسعة وسرعات نقل البيانات |
| **W03** | طوبولوجيا الشبكات الفيزيائية والمنطقية (Topologies Réseau) | 2H نظري + 2H مخبر | طوبولوجيا الناقل (Bus)، النجمة (Étoile)، الحلقية (Anneau)، والمش تركيبي |
| **W04** | النموذج المرجعي OSI وطبقاته السبع (Modèle OSI) | 2H نظري + 2H مخبر | شرح طبقات: الفيزيائية، ربط البيانات، الشبكة، النقل، الجلسة، العرض، والتطبيق |
| **W05** | نموذج TCP/IP والمقارنة الهندسية مع نموذج OSI | 2H نظري + 2H مخبر | طبقات TCP/IP الأربعة، التغليف (Encapsulation)، ومطابقتها لبروتوكولات الإنترنت |
| **W06** | وسائط النقل الفيزيائية: الكابلات المزدوجة المجدولة (UTP/STP) | 2H نظري + 2H مخبر | فئات الكابلات (Cat 5e, Cat 6)، موصلات RJ45، وصنع كابل مستقيم وكابل متقاطع |
| **W07** | وسائط النقل المتقدمة: الألياف البصرية (Fibre Optique) واللاسلكي (Wi-Fi) | 2H نظري + 2H مخبر | مبدأ الانعكاس الضوئي، معايير Wi-Fi (802.11)، والترددات 2.4GHz و 5GHz |
| **W08** | معدات الربط والتوزيع: المحول (Switch) وجهاز التوجيه (Routeur) | 2H نظري + 2H مخبر | دور السويتش في الطبقة 2 وجدول العناوين MAC، ودور الراوتر في الطبقة 3 |
| **W09** | العنونة المنطقية IPv4 وبنية العنوان وقناع الشبكة (Masque de sous-réseau) | 2H نظري + 2H مخبر | الأقسام الأربعة، فئات العناوين (Classes A, B, C)، والعناوين الخاصة والعمومية |
| **W10** | تقسيم الشبكات إلى شبكات فرعية (Subnetting / VLSM) | 2H نظري + 2H مخبر | استعارة البتات، حساب عدد الشبكات الفرعية والأجهزة المتاحة، وعنوان البث Broadcast |
| **W11** | التكوين اليدوي والآلي لعناوين IP: بروتوكول DHCP | 2H نظري + 2H مخبر | إعداد خادم DHCP، توزيع العناوين التلقائي، ومفهوم مدة الإيجار (Lease Time) |
| **W12** | نظام أسماء النطاقات (DNS) وتصفح الإنترنت | 2H نظري + 2H مخبر | ترجمة الأسماء إلى عناوين IP، التسلسل الهرمي للـ DNS، وملف hosts |
| **W13** | أدوات الفحص والتشخيص الشبكي (Ping, Traceroute, Ipconfig, Netstat) | 2H نظري + 2H مخبر | فحص الاتصال، تتبع مسارات الحزم، واكتشاف انقطاع الكابلات أو تعارض العناوين |
| **W14** | خدمات الإنترنت الأساسية: الويب (HTTP/HTTPS) ونقل الملفات (FTP) | 2H نظري + 2H مخبر | بروتوكولات نقل الصفحات وتأمين SSL/TLS ونقل المستندات عبر برامج FTP |
| **W15** | أمن الشبكات وجدران الحماية (Firewall) والشبكات الافتراضية (VPN) | 2H نظري + 2H مخبر | تصفية المنافذ، تشفير الاتصالات عن بعد، وتأمين نقاط الوصول اللاسلكية (WPA2/WPA3) |
| **W16** | مشروع تطبيقي تركيبي: محاكاة وتوصيل شبكة مؤسسة كاملة عبر Packet Tracer | 1H نظري + 3H مخبر | تصميم شبكة متكاملة برواوتر وسويتشات وخوادم ويب وDHCP واختبار الاتصال |
| **W17** | التقييم التحصيلي والامتحان النهائي لمقياس الشبكات والإنترنت | 2H كتابي + 2H تطبيقي | اختبار نظري وتطبيقي في إعداد العنونة وتشخيص وتوصيل الشبكة |
