# التدرج البيداغوجي لـ 17 أسبوعاً - المقياس: MC10
**تنظيم المؤسسات والاقتصاد (Organisation des entreprises)**  
*الحجم الساعي: 5 ساعات أسبوعياً دروس ومحاضرات - 51 ساعة*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى والأهداف المستهدفة |
| :---: | :--- | :---: | :--- |
| **W01** | مدخل إلى علم الاقتصاد وتاريخ الفكر الاقتصادي | 5H Cours | مفهوم الندرة، الحاجات الإنسانية، والنشاط الاقتصادي ودور المؤسسة |
| **W02** | الأعوان الاقتصاديون والدورة الاقتصادية (Circuit Économique) | 5H Cours | الأسر، المؤسسات، البنوك، الإدارات العمومية، وتدفق السلع والأموال |
| **W03** | عوامل الإنتاج: العمل ورأس المال والتنظيم | 5H Cours | رأس المال الثابت والمتداول، الموارد البشرية، والإنتاجية والكفاءة |
| **W04** | مفهوم المؤسسة الاقتصادية وأهدافها ووظائفها الأساسية | 5H Cours | تعريف المؤسسة، الأهداف الربحية والاجتماعية، ودورها في التنمية |
| **W05** | تصنيف المؤسسات حسب الحجم والقطاع والملكية | 5H Cours | المؤسسات المصغرة (TPE)، المتوسطة، والكبيرة، والقطاع العام والخاص |
| **W06** | الأشكال والأنماط القانونية للشركات في القانون الجزائري (SARL, EURL) | 5H Cours | الشركة ذات المسؤولية المحدودة ومؤسسة الشخص الوحيد وخصائصها |
| **W07** | شركات الأموال: شركة المساهمة (SPA) والشركات المدنية | 5H Cours | شروط التأسيس، رأس المال الأدنى، ومسؤولية الشركاء والمديرين |
| **W08** | الهيكل التنظيمي للمؤسسة (L'Organigramme): المفهوم والأنواع | 5H Cours | الهيكل الخطي، الوظيفي، والمختلط (Staff and Line)، ومزايا كل نمط |
| **W09** | رسم وتحليل الهياكل التنظيمية وقراءة خطوط السلطة | 5H TD | ورشة تدريبية على قراءة الهيكل التنظيمي لشركة صناعية واستخراج العلاقات |
| **W10** | الوظائف الكبرى داخل المؤسسة: وظيفة الإدارة والقيادة | 5H Cours | مفهوم التسيير (Management)، التخطيط، التنظيم، التوجيه، والرقابة |
| **W11** | الوظيفة التقنية ووظيفة الإنتاج والرقمنة | 5H Cours | إدارة سلاسل الإنتاج، الصيانة، ودور قسم الإعلام الآلي والرقمنة في المؤسسة |
| **W12** | الوظيفة التجارية والتسويقية (Marketing et Vente) | 5H Cours | دراسة السوق، المزيج التسويقي (المنتج، السعر، التوزيع، الترويج) |
| **W13** | الوظيفة المالية والمحاسبية والموارد البشرية (GRH) | 5H Cours | إدارة الميزانية، السيولة، التوظيف، الأجور، وتطوير كفاءات العاملين |
| **W14** | الهيئات الاقتصادية الوطنية في الجزائر: الغرفة التجارية (CACI) | 5H Cours | دور الغرفة الجزائرية للتجارة والصناعة، وخدمات دعم المؤسسات والابتكار |
| **W15** | المركز الوطني للإعلام الآلي والإحصاء (CNIS) وأجهزة الدعم | 5H Cours | دور الإحصائيات الرسمية في التخطيط، والوكالات الوطنية لدعم التشغيل والمقاولاتية |
| **W16** | دراسة حالة شاملة: إنشاء وتسيير مؤسسة خدمات رقمية ناشئة (Startup) | 5H TD | إعداد خطة تنظيمية كاملة لمؤسسة برمجية ناشئة بهيكلها ووظائفها |
| **W17** | التقييم التحصيلي والامتحان النهائي لمقياس تنظيم المؤسسات | 5H Examen | امتحان شامل يجمع المفاهيم الاقتصادية والتحليل التنظيمي والأنماط القانونية |
