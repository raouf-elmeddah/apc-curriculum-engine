# التدرج البيداغوجي لـ 17 أسبوعاً - المقياس: MC5 (الجزء 2)
**الإعلام الآلي المكتبي - الجداول المتقدمة Excel**  
*الحجم الساعي: 3 ساعات أسبوعياً (1H نظري + 2H مخبر) - 51 ساعة*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى والأهداف المستهدفة |
| :---: | :--- | :---: | :--- |
| **W01** | بيئة برنامج الجداول الإلكترونية (MS Excel) ومفاهيم المصنف | 1H نظري + 2H مخبر | المصنف (Classeur)، أوراق العمل (Feuilles)، الخلايا، والأعمدة والأسطر |
| **W02** | إدخال وتنسيق البيانات وتخصيص نوع الخلايا | 1H نظري + 2H مخبر | تنسيق الأرقام، العملات، النسب المئوية، التواريخ، والحدود والمحاذاة |
| **W03** | السلاسل التلقائية ومقبض التعبئة السحرية (Recopie incrémentée) | 1H نظري + 2H مخبر | توليد الأرقام، الأيام، والشهور تلقائياً واستخدام ميزة الفلاش للتعبئة |
| **W04** | الصيغ الحسابية الأساسية (+, -, *, /) والنسب المئوية | 1H نظري + 2H مخبر | كتابة أول صيغة رياضية تبدأ بعلامة (=)، وحساب فواتير مبيعات وضرائب |
| **W05** | المراجع النسبية والمراجع المطلقة وتثبيت الخلايا بالرمز $ | 1H نظري + 2H مخبر | الفارق الحاسم بين A1 و $A$1 لتفادي أخطاء الحساب عند سحب المعادلات |
| **W06** | الدوال الإحصائية والحسابية الأساسية: SOMME, MOYENNE, MAX, MIN | 1H نظري + 2H مخبر | استخدام شريط الدوال وحساب مجاميع ومعدلات الأقسام بضغطة زر |
| **W07** | الدوال المنطقية البسيطة: الدالة الشرطية (SI / IF) | 1H نظري + 2H مخبر | اختبار الشروط وتحديد النتائج التلقائية (ناجح/راسب، خصم/بدون خصم) |
| **W08** | الدوال المنطقية المركبة والشروط المتعددة (SI.CONDITIONS, ET, OU) | 1H نظري + 2H مخبر | الجمع بين عدة شروط لتحديد فئات الرواتب وسلم المكافآت التلقائي |
| **W09** | دوال الإحصاء الشرطي: NB.SI و SOMME.SI و MOYENNE.SI | 1H نظري + 2H مخبر | حساب عدد المتربصين الناجحين أو مجموع مبيعات صنف معين بناءً على معيار |
| **W10** | دوال البحث والمطابقة الحيوية: الدالة RECHERCHEV (VLOOKUP) | 1H نظري + 2H مخبر | جلب اسم العميل وسعر السلعة تلقائياً بمجرد إدخال رقمه التعريفي |
| **W11** | التنسيق الشرطي للبيانات (Mise en forme conditionnelle) | 1H نظري + 2H مخبر | تلوين الخلايا التي تحتوي درجات أقل من 10 بالأحمر والأعلى بالأخضر آلياً |
| **W12** | إنشاء وتخصيص الرسوم البيانية التوضيحية (Graphiques Excel) | 1H نظري + 2H مخبر | مخططات الأعمدة، الدائرية، والخطية، وإضافة العناوين والنسب التوضيحية |
| **W13** | إدارة قواعد البيانات والجداول في Excel: الفرز والتصفية المتقدمة | 1H نظري + 2H مخبر | فرز الجداول بمتغيرات متعددة وتطبيق الفلاتر الذكية لاستخراج السجلات |
| **W14** | الجداول المحورية التلخيصية (Tableaux Croisés Dynamiques - TCD) | 1H نظري + 2H مخبر | تلخيص آلاف البيانات في ثوانٍ، وتجميع المبيعات حسب المنطقة والشهر |
| **W15** | إعداد الصفحة للطباعة الرسمية ومعالجة هوامش الجداول الكبيرة | 1H نظري + 2H مخبر | ضبط منطقة الطباعة (Zone d'impression)، تكرار أسطر العناوين، وضبط مقياس الصفحة |
| **W16** | مشروع تطبيقي تركيبي: تصميم لوحة تحكم ومحاسبة متكاملة (Dashboard) | 1H نظري + 2H مخبر | بناء نظام متابعة مبيعات وإحصائيات متكامل بالمعادلات والرسوم المحورية |
| **W17** | التقييم التحصيلي والامتحان التطبيقي في الجداول المتقدمة Excel | 1H كتابي + 2H مخبر | اختبار مخبري فردي في تطبيق الدوال المتقدمة وبناء جدول محوري ورسم بياني |
