**رياضيات الإعلام الآلي (Mathématiques)**  
*الحجم الأسبوعي: 3 ساعات (1H Cours + 2H TD)*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى الرياضي والتطبيقي المستهدف |
| :---: | :--- | :---: | :--- |
| **W01** | نظرية المجموعات: المفاهيم الأساسية والمجموعات الجزئية | 1H Cours + 2H TD | تعريف المجموعة، عناصرها، الانتماء والاحتواء، والمجموعة الخالية |
| **W02** | العمليات الأساسية على المجموعات: الاتحاد والتقاطع | 1H Cours + 2H TD | الاتحاد، التقاطع، المكملة، ومخططات فن (Diagrammes de Venn) |
| **W03** | الفرق المتناظر والجداء الديكارتي (Produit cartésien) | 1H Cours + 2H TD | حساب الجداء الديكارتي والفرق المتناظر وتطبيقاتها في قواعد البيانات |
| **W04** | العلاقات الثنائية والتطبيقات (Relations & Applications) | 1H Cours + 2H TD | أنواع العلاقات (انعكاسية، متناظرة، متعدية) ومفهوم التطبيق الرياضي |
| **W05** | التطبيقات المتباينة والغtrace والتقابلية (Bijection, Injection) | 1H Cours + 2H TD | دراسة التقابل والتطبيق العكسي وأهميته في التشفير والخوارزميات |
| **W06** | الدوال العددية: مجموعة التعريف ونهايات الدوال | 1H Cours + 2H TD | تحديد مجموعة تعريف الدوال الحدودية والكسرية وحساب النهايات |
| **W07** | حالات عدم التعيين وطرق إزالتها والمستقيمات المقاربة | 1H Cours + 2H TD | إزالة عدم التعيين بالتحليل والمرافق ودراسة المستقيمات المقاربة |
| **W08** | حساب المشتقات وقواعد الاشتقاق الأساسية | 1H Cours + 2H TD | مشتقة الدوال المألوفة، مشتقة الجداء والقسمة ودراسة اتجاه التغير |
| **W09** | دراسة دالة حدودية كاملة ورسم جدول التغيرات والمنحنى البياني | 1H Cours + 2H TD | ربط المشتقة بالقيم الحدية ورسم منحنى الدالة بيانياً |
| **W10** | مدخل إلى المصفوفات (Matrices): التعريف والأنواع | 1H Cours + 2H TD | رتبة المصفوفة، المصفوفة السطرية، العمودية، الصفرية، والمربعة |
| **W11** | العمليات الجبرية على المصفوفات: الجمع والضرب في عدد حقيقي | 1H Cours + 2H TD | شروط الجمع وخواصه والضرب في عدد سلمي وتطبيقاتها |
| **W12** | جداء المصفوفات (Produit matriciel) وشروط إمكانيته | 1H Cours + 2H TD | قاعدة ضرب الأسطر في الأعمدة وخواص الجداء (عدم التبديل) |
| **W13** | المصفوفة المطابقة ومحدد المصفوفة من الرتبة الثانية والثالثة | 1H Cours + 2H TD | مصفوفة الوحدة I، حساب المحددات (Déterminants) بطريقة ساروس |
| **W14** | مقلوب مصفوفة مربعة (Inversion d'une matrice) | 1H Cours + 2H TD | شرط قابلية القلب (المحدد لا يساوي صفراً) وحساب المصفوفة الملحقة |
| **W15** | حل جمل المعادلات الخطية بطريقة المصفوفات وطريقة غاوس (Gauss) | 1H Cours + 2H TD | تحويل جملة معادلات إلى شكل مصفوفي وتطبيق تصعيد غاوس |
| **W16** | **حوصلة عامة وتطبيقات برمجية للمصفوفات في الإعلام الآلي** | 1H Cours + 2H TD | ربط المصفوفات الرياضية بالجداول ثنائية الأبعاد في الخوارزميات |
| **W17** | **التقييم التحصيلي والامتحان السداسي في الرياضيات** | 3H Examen | اختبار كتابي شامل يقيس كفاءة حل المسائل الرياضية والمصفوفات |
