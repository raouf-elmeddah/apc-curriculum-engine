# التدرج البيداغوجي لـ 17 أسبوعاً - المقياس: MC2 (الجزء 1)
**تقنيات التعبير والتواصل المهني (Techniques d'expression)**  
*الحجم الأسبوعي: 3 ساعات (Cours + Ateliers)*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى والمهارات المستهدفة |
| :---: | :--- | :---: | :--- |
| **W01** | مدخل إلى الاتصال المؤسساتي ومكونات العملية التواصلية | 3H Cours | عناصر الاتصال (المرسل، المتلقي، الرسالة، القناة، التغذية الراجعة) |
| **W02** | تقنيات القراءة السريعة والقراءة الاستكشافية للنصوص التقنية | 3H Cours | القراءة الانتقائية، تحديد الكلمات الدالة، وتصفح الوثائق المعلوماتية |
| **W03** | تحليل النص التقني: تحديد الفكرة العامة والأفكار الأساسية | 3H TD | تفكيك النص واستخراج سلسلة الأفكار المنطقية ومخطط النص |
| **W04** | تقنية التلخيص (Résumé de texte): القواعد والمعايير المهنية | 3H TD | احترام حجم التلخيص (الربع)، الأسلوب الخاص، والحياد التام للملخص |
| **W05** | ورشة تطبيقية في تلخيص مقال علمي حول الذكاء الاصطناعي | 3H TD | تطبيق عملي جماعي لتلخيص نص تقني ومقارنة النماذج وتصحيحها |
| **W06** | جودة الأسلوب الإداري والتقني: الوضوح، الإيجاز، والموضوعية | 3H Cours | تفادي الحشو، الدقة اللغوية، واستخدام المصطلحات المهنية المباشرة |
| **W07** | تدوين الملاحظات أثناء الاجتماعات وجلسات العمل الفنية | 3H TD | استخدام الرموز، الاختصارات، وهيكلة النقاط الرئيسية في مسودة سريعة |
| **W08** | تحرير المراسلات المهنية: الرسالة الإدارية والبريد الرسمي | 3H TD | أجزاء الرسالة الإدارية (المرجع، الموضوع، التحية، العرض، التوقيع) |
| **W09** | إعداد العرض التقديمي (L'exposé oral): جمع المعلومات والتبويب | 3H TD | مرحلة البحث المكتبي، تنظيم خطة العرض، واستخدام الشرائح التوضيحية |
| **W10** | مهارات الإلقاء والتحدث أمام الجمهور (Communication verbale) | 3H TD | لغة الجسد، نبرة الصوت، ضبط الوقت، والتفاعل مع أسئلة الجمهور |
| **W11** | تحرير محضر الاجتماع (Compte rendu de réunion) | 3H TD | صياغة وقائع الجلسة بدقة وحيادية وفق النموذج الإداري المعتمد |
| **W12** | تحرير محضر التنصيب ومحضر الاستلام (Procès-verbal) | 3H TD | بنية المحضر الرسمي، الصيغ القانونية الملزمة، وبيانات الحضور والشهود |
| **W13** | التقرير التقني (Rapport technique): المفهوم والأنواع | 3H Cours | التمييز بين التقرير الإعلامي، التحليلي، وتقرير الحادث أو الخلل |
| **W14** | تحرير تقرير تقني حول عطل في شبكة أو منصب عمل | 3H TD | صياغة عناصر التقرير: وصف المشكلة، الأسباب، الحلول المتخذة، والتوصيات |
| **W15** | تحرير تقرير تثبيت ومطابقة عتاد وبرمجيات جديدة | 3H TD | توثيق عملية التثبيت ونتائج الفحص ومطابقتها لدفتر الشروط |
| **W16** | **جلسة إلقاء ومناقشة عروض تقنية شفوية لفرق المتربصين** | 3H Ateliers | إلقاء عروض شفوية وتقييم المتربصين في مهارات التواصل والإقناع |
| **W17** | **التقييم التحصيلي والامتحان النهائي في تقنيات التعبير** | 3H Examen | اختبار تحريري يشمل تلخيص نص تقني وصياغة مراسلة أو تقرير إداري |
