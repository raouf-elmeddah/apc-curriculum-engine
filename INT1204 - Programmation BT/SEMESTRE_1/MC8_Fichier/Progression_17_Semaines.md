# التدرج البيداغوجي لـ 17 أسبوعاً - المقياس: MC8
**ملفات المعطيات الكلاسيكية (Fichier)**  
*الحجم الأسبوعي: 4 ساعات (Cours + TD)*

| الأسبوع | عنوان الدرس والوحدة التعليمية | طبيعة الحصة | المحتوى المستهدف |
| :---: | :--- | :---: | :--- |
| **W01** | المفاهيم الأساسية: الحرف (Caractère)، الحقل (Zone/Champ)، والسجل | 4H Cours | تعريف الذرة البيانية، أنواع الحقول (رقمي، ألفبائي، رمزي)، وهيكل السجل |
| **W02** | السجل المنطقي والسجل الفيزيائي وعامل التكتل (Facteur de blocage) | 4H Cours | Enregistrement logique vs physique، ومفهوم الكتلة (Bloc) وحساب سعتها |
| **W03** | أنواع السجلات: السجلات ذات الطول الثابت والمتغير | 4H TD | خصائص Enregistrements de longueur fixe et variable وحساب الهدر البياني |
| **W04** | الخصائص الحركية للملف: النشاط، الحجم، ومعدل النمو | 4H TD | النشاط (Taux d'activité)، الحجم (Volume)، ومعدل الزيادة السنوية للملف |
| **W05** | تصنيف الملفات الوظيفية: الملفات الدائمة (Fichiers permanents/Maître) | 4H Cours | دور الملفات الرئيسية، خصائصها وتحديثها الدوري (مثل ملف الموظفين) |
| **W06** | تصنيف الملفات الحركية والوسيطة (Mouvements, Manœuvres, Archives)| 4H Cours | ملفات الحركات، ملفات المناورة والفرز، وملفات الأرشيف والجداول الثابتة |
| **W07** | المعالجات الأساسية على الملفات: المراقبة والتحقق من صحة البيانات | 4H TD | التحقق من النوع، المجال (Plage de valeurs)، ورقم التحقق (Clé de contrôle) |
| **W08** | عمليات الدمج والفرز والفرز المزدوج (Tri et Fusion) | 4H TD | خوارزميات دمج ملفين مرتبين وخوارزمية التحديث المتزامن |
| **W09** | وسائط التخزين التسلسلية: الأشرطة الممغنطة (Bandes magnétiques) | 4H Cours | مبدأ التسجيل، الفراغات بين الكتل (IBG)، ونمط التسجيل التسلسلي |
| **W10** | وسائط التخزين ذات الوصول المباشر: الأقراص الممغنطة (Disques magnétiques)| 4H Cours | بنية القرص الصلب: الأسطوانة (Cylindre)، المسار (Piste)، والقطاع (Secteur) |
| **W11** | التنظيم التتابعي الفيزيائي (Organisation séquentielle physique) | 4H TD | مبدأ التخزين، خوارزميات القراءة التتابعية، وصعوبات التعديل والحذف |
| **W12** | التنظيم التتابعي المنطقي واستعمال المؤشرات (Pointeurs / Chaînage) | 4H TD | الملفات المربوطة بمؤشرات، التحديث بإعادة توجيه الروابط المنطقية |
| **W13** | التنظيم المفهرس (Organisation séquentielle indexée) | 4H TD | منطقة البيانات ومنطقة الفهارس، البحث السريع عبر جداول الفهارس |
| **W14** | التنظيم بالعنونة المباشرة والنسبية (Organisation adressée / Directe) | 4H TD | حساب عنوان التسجيل انطلاقا من المفتاح، ومفهوم دوال التقطيع (Hachage) |
| **W15** | معالجة التصادمات في العنونة المباشرة (Gestion des collisions) | 4H TD | تقنيات معالجة التصادم: السبر الخطي، والقوائم المربوطة الفائضة |
| **W16** | **دراسة حالة مقارنة وشاملة لاختيار تنظيم الملف الأنسب لنظام واقعي**| 4H TD | دراسة مقارنة لأنظمة البنوك، المستشفيات، وسجلات الحالة المدنية |
| **W17** | **التقييم التحصيلي والامتحان النهائي لمقياس الملفات** | 4H Examen | اختبار شامل في هيكلة الملفات وخوارزميات المعالجة والحسابات |
